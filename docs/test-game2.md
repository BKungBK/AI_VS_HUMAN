# วิธีทดสอบเกม 2 — Swipe Court

## เปิดเกม

ที่โฟลเดอร์โปรเจกต์ติดตั้งแพ็กเกจตาม lockfile หากเครื่องยังไม่มี `node_modules` แล้วเริ่มเซิร์ฟเวอร์ หากเกมแรกยังใช้พอร์ต 5180 อยู่ ให้ใช้พอร์ต/ฐานข้อมูลแยกตามนี้:

```powershell
npm install
$env:GAME_PORT='5181'
$env:GAME_DATA_DIR='data/pg-game2'
npm run game:start
```

เมื่อใช้ค่าข้างบน เปิด [http://localhost:5181/games](http://localhost:5181/games); ถ้าใช้พอร์ตเริ่มต้น ให้เปลี่ยน URL เป็น `http://localhost:5180/games` ผู้จัดใช้รหัสใน `data/host-key.txt` เข้าระบบและสร้างห้องใหม่ ในหน้า Host เปิด “จัดการรอบและเปลี่ยนคิว” แล้วเลือกคิว `03.05 Swipe Court` เปิดหน้า Player จาก QR/ลิงก์ และเปิดหน้า Display แยกอีกแท็บหรืออีกจอ

Player กรอกชื่อและเลือกกลุ่ม รอให้เห็น “ภาพพร้อม 8/8” และ “พร้อมเล่นแล้ว” แล้ว Host กด “เริ่ม 8 ภาพ” เกมนับถอยหลัง 3 วินาที รับคำตอบภาพละ 4 วินาทีครบ 8 ภาพ จากนั้นเฉลยภาพละ 3 วินาทีและสรุปอีก 6 วินาที ปุ่ม Host จึงเปิดให้กด “ยืนยันผล / ไปคิว 03.03” เกมไม่จบหรือเปลี่ยนสไลด์ให้เอง

หาก Host เริ่มก่อนบางเครื่องพร้อม เครื่องที่ยังโหลดภาพปัจจุบันไม่จบจะตอบไม่ได้ใน deadline เดิม; เริ่มได้แต่ไม่มีการชดเชยเวลารายคน

## สิ่งที่ควรตรวจ

- ซ้ายและปุ่ม Human ให้คำตอบเดียวกัน; ขวาและปุ่ม AI ให้คำตอบเดียวกัน การปัดสั้นกว่าเกณฑ์ไม่ส่งคำตอบ
- คำตอบแรกของผู้เล่นต่อภาพล็อกไว้ การกดหรือปัดซ้ำไม่เพิ่มคะแนน และคำตอบเก่าใช้กับภาพใหม่ไม่ได้
- ก่อนรอบที่ 8 ปิด ต้องไม่พบ `classification`, creator, source URL, license, reveal text หรือ prompt ใน snapshot/API ของผู้เล่นและจอฉาย
- ระหว่างเกมแสดงภาพเดียวกันทุกรายและไม่เปิดคะแนนถูก/ผิด หลังครบ 8 ภาพจึงค่อยเปิดคำตอบ เครดิต และสถิติ
- ตอบถูก 8 ภาพได้ 800 คะแนน; ผิด/ไม่ตอบได้ 0 สำหรับภาพนั้น คะแนนกลุ่มหารด้วย roster ตอน Start รวมผู้เล่นที่ไม่ตอบ
- ภาพที่ไม่มี accepted answers แสดง “ไม่มีคำตอบ” ไม่แสดง `NaN`; สัดส่วน Human/AI รวมเป็น 100 เมื่อมีคำตอบ
- จอฉายกลับเข้าคิว 03.03 ได้หลัง Host ยืนยันเท่านั้น

## ตรวจอัตโนมัติ

```powershell
npm run game:build
npm run game:test
$env:GAME_TEST_ORIGIN='http://127.0.0.1:5181'
npm run game:qa2
```

เมื่อรันเกมแรกค้างที่พอร์ต 5180 ให้กำหนด `GAME_TEST_ORIGIN` เป็น 5181 ตามตัวอย่าง; ถ้าเกม 2 รันพอร์ตเริ่มต้น 5180 ให้เปลี่ยน URL ในตัวแปรเป็นพอร์ตนั้น `game:qa2` ใช้ Chrome/Playwright ที่ติดตั้งอยู่แล้ว สร้างห้องใหม่ เล่นครบ 8 รอบจริง ตรวจการปัดครั้งแรก ความเป็นส่วนตัว และการยืนยันผล แล้วเขียนภาพตรวจไว้ใน `qa/game2/` ใช้เวลาประมาณหนึ่งนาทีเพราะเคารพเวลารอบจริงและเวลาเฉลย

โปรเจกต์มี dependency ของเกม/API และ Playwright อยู่แล้ว งานนี้ไม่ได้เพิ่มแพ็กเกจใหม่
