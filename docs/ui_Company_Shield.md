บนหัวจอทุกมุมมอง (Player, Display, Host) จะแสดงกรอบข้อความสีเหลืองอำพันสะท้อนบทเรียนคดีจริง:

> 🏢 **บริบทคดีจริง (PINNED CONTEXT — AIR CANADA 2024)**  
> *“คดี Moffatt v. Air Canada: คณะพิจารณาข้อพิพาทแพ่งบริติชโคลัมเบียให้สายการบินรับผิดจากข้อมูลค่าโดยสารกรณีสูญเสียสมาชิกครอบครัวที่แชตบอตให้ไม่ตรงนโยบาย ข้อความในเกมเป็นสถานการณ์จำลอง”*

## 4. สนามการเล่นและรางวิ่ง 3 ช่อง (3-Lane Arena Architecture)

```
        [ 🤖 AIR-SERVICE BOT RUNWAY (จุดปล่อยคำตอบ) ]
               ┌──────────┬──────────┬──────────┐
               │  ช่อง 0   │  ช่อง 1   │  ช่อง 2   │
               │ (ซ้าย L)  │ (กลาง C)  │ (ขวา R)  │
               └────┬─────┴────┬─────┴────┬─────┘
                    │          │          │
    y = 0% to 70%   │    🎯    │    💬    │     (แพ็กเก็ตพุ่งลงมาด้วยความเร็ว)
                    │          │          │
════════════════════╪══════════╪══════════╪═════════════════════  y = 70%
                    │  [ 🏢 COMPANY SHIELD ]   (เลื่อนบนรางกลางขวางไว้)
════════════════════╪══════════╪══════════╪═════════════════════
                    │          │          │
   y = 70% to 100%  │          │    💥    │     (หากไม่ขวาง จะพุ่งชนลูกค้า)
                    ▼          ▼          ▼
               ┌──────────┬──────────┬──────────┐
               │ 👤 ลูกค้า │ 👤 ลูกค้า │ 👤 ลูกค้า │   y = 100% (จุดรับเคราะห์)
               └──────────┴──────────┴──────────┘
```

1. **3 ช่องเลน (Lanes):**
   - **ช่อง 0 (ซ้าย / L):** นโยบายคืนเงิน, ลดหย่อนตั๋ว, การยกเลิก
   - **ช่อง 1 (กลาง / C):** การคำนวณราคา, ส่วนลดพิเศษ, สิทธิ์สะสมไมล์
   - **ช่อง 2 (ขวา / R):** ค่าธรรมเนียมสัมภาระ, อัปเกรดที่นั่ง, ข้อจำกัดสัมภาระ
2. **วงจรชีวิตของแพ็กเก็ต (Packet Lifecycle):**
   - **Aiming (0.8s):** หัวรางเล็งเป้าด้วยเลเซอร์สีแดงกระพริบ + เสียง Aiming Ping
   - **Dropping (0.8s):** แคปซูลข้อความบอตพุ่งลงมาจาก $y = 0\%$ สู่ $y = 70\%$ พร้อมเสียง Launch
   - **Decision Point ($y = 70\%$):**
     - **บริษัทขวางทัน (Intercepted / Blocked):** เกิดแอนิเมชันกระแทกเด้ง (Squash & Stretch Recoil) + ประกายไฟสีฟ้า + เสียงโล่เหล็กปะทะ `Clank` $\to$ ข้อความกลายเป็น **"ใบงานบริษัท (Task Card)"** ได้รับ `+50` แต้ม!
     - **หลุดลอดไป (Missed / Customer Breach):** แคปซูลพุ่งทะลุถึงลูกค้าที่ $y = 100\%$ เกิดควันสีแดง + ลูกค้าร้องตกใจ `Damage Alarm` $\to$ เสียหลอดความเชื่อมั่นลูกค้า (Customer Trust Slot) ทันที `0` แต้ม

## 6. กฎคะแนนและการคำนวณ (Scoring & Denominator Invariant)

1. **คะแนนส่วนบุคคล (Individual Score):**
   - รับเรื่องทัน (Blocked): `+50` แต้มต่อแพ็กเก็ต
   - รับเรื่องไม่ทัน (Missed): `0` แต้ม (เสียความเชื่อมั่นลูกค้า)
   - คะแนนเต็มสูงสุด: **500 แต้ม** (10 แพ็กเก็ต $\times$ 50 แต้ม)
2. **คะแนนกลุ่มเฉลี่ย (Group Score Invariant):**
   $$\text{Group Score} = \frac{\sum \text{คะแนนของผู้เล่นในกลุ่ม}}{\text{จำนวนสมาชิกทั้งหมดในกลุ่มตั้งแต่เริ่มเกม}}$$
   - หากผู้เล่นในกลุ่มไม่ได้กด หรือหลุดจากเกม ตัวส่วน (Denominator) จะยังคงนับผู้เล่นทุกคนในรายชื่อตั้งต้นเสมอ

## 8. ระบบเสียงสังเคราะห์ Procedural Web Audio API

สร้างเสียงสังเคราะห์ขึ้นสดผ่านเบราว์เซอร์ 100% ไม่พึ่งพาไฟล์ภายนอก:

- `playAim()`: เสียงความถี่สูง Ping สองจังหวะ (1200Hz $\to$ 1600Hz) เมื่อเริ่มเล็ง
- `playLaunch()`: เสียงไซเรนพุ่งลงมา (800Hz $\to$ 400Hz)
- `playShieldBlock()`: เสียงโลหะกระทบแน่นหนา (Low Sine 150Hz + Bandpass Metal 450Hz ค้าง 0.25s)
- `playCustomerHit()`: เสียงออดเตือนภัย (Square Wave 220Hz สลับ 180Hz) เมื่อลูกค้าโดนชน
- `playSlideMove()`: เสียงเลื่อนรางสั้นนุ่มนวล (Bandpass Noise Sweep 300Hz $\to$ 600Hz)
- `playCountdownTick()` / `playCountdownGo()`: เสียงนับถอยหลัง 3-2-1-GO
- `playTimesUp()`: เสียงหมดเวลา 25 วินาที

- **บทเรียนคดี Air Canada 2024:** ระบุข้อเท็จจริงของคดี Moffatt อย่างเจาะจง และแยกจากกิจกรรมจำลอง; บทสรุปกิจกรรมคือ **“AI IS A TOOL. NOT A SHIELD.”** (AI เป็นเครื่องมือ ไม่ใช่โล่กำบังความรับผิดชอบของบริษัท)
