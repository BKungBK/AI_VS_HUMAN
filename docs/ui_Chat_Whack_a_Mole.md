## 3. แบนเนอร์บริบทค้าง (Pinned Context Banner)

บนหัวจอทุกมุมมอง (Player, Display, Host) จะแสดงกรอบข้อความเตือนภัยสีเหลืองอำพันค้างตลอดเวลา:

> ⚠️ **บริบทของสถานการณ์ (PINNED CONTEXT)**  
> *“ผู้ใช้ขอคุยกับเจ้าหน้าที่ และบอกว่าคำแนะนำเดิมทำให้ไม่สบายใจ”*

ทุกข้อความที่บอตตอบกลับมาในเกมนี้ จะต้องถูกประเมินภายใต้บริบทนี้เท่านั้น โดยผู้เล่นรับบทเป็น **"ผู้ตรวจกลั่นกรองข้อความ (Chat Moderator)"** ที่มีอำนาจสั่งหยุดข้อความไม่ให้ส่งถึงผู้ใช้

## 4. สนามการเล่นและกริด 2 คอลัมน์ × 3 แถว (2×3 Grid)

1. **ขนาดกริด:** ช่อง 6 ช่อง (Index 0 ถึง 5) ขนาดคงที่ ไม่เลื่อน ไม่ยุบตัว
2. **ความจุสูงสุด:** ฟองแชตโผล่พร้อมกันได้สูงสุด **3 ฟอง** (ไม่มีการใช้ช่องที่ยังไม่ว่างทับกัน)
3. **อายุฟอง:** ฟองละ **2.4 วินาที** มีแถบเวลาสีฟ้า (`--whack-cyan`) หดจาก 100% → 0% ที่ขอบล่าง
4. **การทุบ:** แตะที่ฟอง 1 ครั้ง ฟองจะถูกประทับตราขนาดใหญ่เอียง -5 องศา **"🛑 หยุด / ส่งตรวจ"** ทันที พร้อมเสียงค้อนกระแทก
5. **ไม่ใช้การจำตำแหน่ง:** แต่ละช่องมีพื้นที่แตะกว้างขวาง $\ge 105\text{px}$ ป้องกันการแตะพลาด

## 6. กฎคะแนนและการคำนวณ (Scoring & Clamping Rules)

1. **การคิดคะแนนเดี่ยว (Individual Scoring):**
   - **ทุบข้อความที่ควรหยุด (STOP):** ได้รับ `+100` แต้มดิบ
   - **ทุบข้อความที่ควรปล่อยผ่าน (PASS):** ถูกหัก `-100` แต้มดิบ
   - **พลาดข้อความที่ควรหยุด (Missed STOP):** ได้รับ `0` แต้ม
   - **ปล่อยผ่านข้อความช่วยเหลือ (Ignored PASS):** ได้รับ `0` แต้ม (ถูกต้องตามเป้าหมาย)
   - **ไม่ clamp ระหว่างเล่น:** เพื่อป้องกันไม่ให้การทุบข้อความผิดก่อนเริ่มสะสมคะแนนกลายเป็นการทุบฟรี
   - **Clamp คะแนนสุดท้ายเมื่อหมดเวลา:**
     $$\text{Final Score} = \text{clamp}(100 \times \text{CorrectHits} - 100 \times \text{WrongHits}, 0, 900)$$
   - คะแนนเดี่ยวสูงสุด = `900` แต้ม (ทุบข้อความเสี่ยงครบทั้ง 9 ฟอง และไม่ทุบข้อความดีเลย)
   - หากทุบครบทั้ง 18 ฟอง = $(9 \times 100) - (9 \times 100) = 0$ แต้ม

2. **คะแนนกลุ่ม (Group Average & Denominator Invariant):**
   $$\text{Group Score} = \frac{\sum \text{Scores of Group Members}}{\text{Total Starting Roster in Group}}$$
   - สมาชิกที่ได้ 0 คะแนน ยังคงถูกนำมาหารในตัวส่วนเสมอ

## 8. ระบบเสียง Procedural Web Audio API (`src/game-client/whack-sound.ts`)

- `playSpawn()`: คลื่นเสียง Sine Sweep $320 \to 680\text{ Hz}$ นุ่มนวลเมื่อฟองเกิดใหม่
- `playWhack()`: เสียงค้อนกระแทกทุบ Mallet Slam ($160 \to 38\text{ Hz}$ Triangle pitch drop + White noise snap)
- `playCorrect()`: เสียงระฆังคู่ Harmonics ($880\text{ Hz} \to 1318.5\text{ Hz}$) ยืนยันการหยุดข้อความเสี่ยง
- `playWrong()`: เสียง Sawtooth buzz เตือนภัยต่ำ $180\text{ Hz}$ เมื่อทุบข้อความดี
- `playTick()`: เสียง Tick เมโทรนอมความถี่ $900\text{ Hz}$ ช่วงนับถอยหลัง 3 วินาที
- `playTimesUp()`: เสียงฆ้องคู่ $440 \to 220\text{ Hz}$ เมื่อหมดเวลา 25 วินาที
- รองรับปุ่มเปิด/ปิดเสียงบนหัวจอของผู้เล่น
