# วิธีทดสอบเกม 3 — Caption & Prompt Battle

เปิด `Start-Game3.cmd` แล้วเข้า [หน้าเกมที่พอร์ต 5182](http://localhost:5182/games?game=caption-battle) พอร์ตนี้แยกจากเกมแรก/สองที่เปิดอยู่ รหัสผู้จัดอยู่ที่ `data/host-key.txt` เข้าระบบ เลือก “3 · Caption & Prompt Battle” ใน “เกมสำหรับห้องใหม่” แล้วสร้างห้อง หรือเปิดห้องเดิมแล้วใช้ “จัดการรอบและเปลี่ยนคิว” เลือก `04.01 Caption & Prompt Battle`

อ่านภาพ/โจทย์และแคปชั่น AI แล้วกด “อนุมัติโจทย์และแคปชั่น AI” เปิด Player จาก QR/ลิงก์ ให้ผู้เล่นเลือกกลุ่ม แล้วเปิด Display อีกจอ มือถือใน Wi-Fi เดียวกันใช้ [LAN URL](http://192.168.1.143:5182/games) หรือ URL ที่ server แสดงเมื่อ IP เปลี่ยน

กด “เริ่มเขียน 20 วินาที” ทุกคนเขียนเอง หลัง countdown 3 วิ ระบบบันทึกร่างทุก 1 วิและส่งทันทีได้ ตรวจผลงาน 60 วิด้วยปุ่มผ่าน/ไม่ผ่าน/งดเผยแพร่ (สองอย่างหลังต้องใส่เหตุผล) ถ้าทุกงานตรวจครบ รอถึงปลายช่วงแล้วเปิดเลือกตัวแทน 10 วิอัตโนมัติ หากตรวจไม่ครบ เกมจะค้าง REVIEW_REQUIRED จนตรวจครบและกดเปิดเลือกตัวแทนเอง

รอบสุดท้าย 20 วิเป็นรหัสนิรนาม โหวตกลุ่มตัวเองไม่ได้ ปิดแล้วเผยเจ้าของ จำนวนเสียง support และคะแนน ผู้จัดกด “ยืนยันผล / ไปคิว 04.02” ครั้งเดียวเพื่อบันทึกคะแนนและกลับสไลด์ ไม่มี auto-finish

## เปิดจากเทอร์มินัล

```powershell
$env:GAME_PORT='5182'
$env:GAME_DATA_DIR='data/pg-game3'
npm run game:build
npm run game:start
```

## ตรวจอัตโนมัติ

```powershell
npm run game:test
$env:GAME_TEST_ORIGIN='http://127.0.0.1:5182'
npm run game:qa3
```

QA สร้างห้องใหม่ ไม่แก้ห้องของผู้ใช้ จำลอง roster 32 คนใน 6 กลุ่ม เล่นตามเวลาจริง ส่ง draft/revision พร้อมกัน จงใจทิ้งหนึ่งงานไว้ให้เกิด REVIEW_REQUIRED ทดสอบ UI อนุมัติและเปิดโหวต ตรวจ privacy, HTTP 81 graphemes, reconnect, own-group block, final votes 32 เสียง และยืนยันผลครบ เขียนภาพ/รายงานที่ `qa/game3/` โดยใช้ Chrome ที่ติดตั้งในเครื่อง

การซ้อมจำลองในเครื่องไม่ใช่การรับรอง Wi-Fi หรือความเร็วตรวจงานของผู้จัดจริง ก่อนใช้หน้างานยังต้องซ้อมกับมือถือและผู้ตรวจ 32 งานจริงตามเวลา 60 วิ

ภาพชื่อ `*-max.png` ใช้ snapshot fixture สำหรับตรวจ layout เท่านั้น โดยยืดข้อความครบทั้ง 7 ผลงานเป็น 80 graphemes ไม่มีการแก้แคปชั่น AI ที่ล็อกในฐานข้อมูลหรือผลคะแนนจริง ต้องซ้อมเปรียบเทียบข้อความยาวบนมือถือภายใน 20 วินาทีกับผู้เล่นจริงเพิ่มเติม
