## 3. การจัดหน้าตามบทบาท (Responsive Surface Layouts)

### 3.1 Player Mobile (เป้าหมาย 390×844 px และรองรับ 320 px)
- **Header:** แถบข้อมูลผู้เล่น แสดงชื่อเล่น, กลุ่ม, คะแนนสะสม และ Badge สถานะชีวิต (`ALIVE` เรืองแสงชีพจรสีเขียว / `DEAD` หัวกะโหลกสีแดง)
- **Phase Clock:** นาฬิกา 4 วินาทีขนาดใหญ่ กะพริบและส่งเสียง tick เมื่อเหลือเวลา ≤ 2 วินาที
- **Claim Card:** กรอบคำกล่าวอ้างขนาดใหญ่ ชัดเจน อ่านง่าย ไม่ crop ข้อความ
- **Mushroom Photo (รอบที่ 6):** แสดงภาพถ่ายเห็ดระโงกหินจริง พร้อมขอบเตือนภัยสีแดงและป้ายกำกับ `LETHAL RISK`
- **Tactile Decision Buttons:**
  - **เชื่อ (BELIEVE):** สีเขียวป่าลึก ปุ่มสัมผัสขนาดใหญ่ขั้นต่ำ 100px เขียนคำเตือนชัดเจนว่า *"ถูกได้ +300 แต้ม | ผิด = ตายทันที"*
  - **ไม่เชื่อ (DOUBT):** สีเหลืองอำพัน ปลอดภัย *"ผิดได้ +100 แต้ม | รอดปลอดภัย"*
- **Locked Banner:** เมื่อกดยืนยันแล้ว ล็อกคำตอบทันที ไม่ให้เปลี่ยน พร้อมแสดงเครื่องหมายยืนยัน
- **Ghost Spectator HUD:** หากผู้เล่นเสียชีวิต หน้าจอจะเปลี่ยนเป็นโหมดผู้ชมวิญญาณสีดำโปร่งแสง แสดงรอบและสาเหตุที่เสียชีวิต แต่ยังคงชมเกมสดและให้กำลังใจเพื่อนในกลุ่มได้

### 3.2 Display Projector (เป้าหมาย 1920×1080 px ฉายระยะไกล 10 เมตร)
- **Header:** โค้ดห้อง, คิวสไลด์ `07.01`, รอบปัจจุบัน `รอบที่ X จาก 6`
- **Main Stage Card:** วางอยู่ด้านซ้าย ตัวอักษรคำกล่าวอ้างขนาด 28–42px คมชัด พร้อมเกจ `[AI CONFIDENCE: 99.8%]`
- **Live Statistics Column:** วางอยู่ด้านขวา แสดงตัวเลขนับถอยหลัง, จำนวนผู้เล่นที่ยังมีชีวิต / เสียชีวิตแล้ว / ส่งคำตอบแล้ว
- **Group Survival Matrix:** ตาราง 6 กลุ่ม แสดงสัดส่วนผู้รอดชีวิต `alive / total` (เช่น `4/5 (80%)`) และแต้มรวมของกลุ่มแบบเรียลไทม์
- **Dramatic Reveal Stage:** เมื่อหมด 4 วินาที จะเข้าสู่ช่วงเฉลย 5 วินาที พร้อมแบนเนอร์ขนาดใหญ่แสดงว่าข้อความ *"ถูกต้อง"* หรือ *"ภาพหลอน / ผิดจริง"* พร้อมจำนวนผู้เสียชีวิตในรอบนั้น
- **Final Results Screen:** โพเดียมสรุปคะแนนเฉลี่ยทั้ง 6 กลุ่ม จัดอันดับ 1–6 และเปิดดูประวัติการตัดสินใจทั้ง 6 รอบจากส่วนพับได้ เพื่อให้ผลและอันดับอ่านง่ายบนมือถือ

## 4. สถานะและจังหวะของเกม (Phase State Machine & Timing)

| เฟส | ระยะเวลา | สิ่งที่ผู้เล่น / ผู้จัด / จอฉายเห็น |
|---|---|---|
| **PREVIEW** | ไม่จำกัด | แสดงกติกา 6 รอบ, ซ้อมทำความเข้าใจ (รอบ 0), ผู้เล่นส่ง ready เมื่อพร้อม |
| **COUNTDOWN** | 3 วินาที | นับถอยหลังเตรียมตัวรอบที่ 1 พร้อมข้อความเตือนใจ |
| **ANSWERING** | 4 วินาที | คำกล่าวอ้างแสดงพร้อมกันทุกเครื่อง, ผู้เล่นที่มีชีวิตเลือก "เชื่อ" หรือ "ไม่เชื่อ", คำตอบแรกถูกล็อกทันที, เฉลยถูกซ่อนโดยเด็ดขาด |
| **REVEAL** | 5 วินาที | เปิดเผยความจริง (True/False) พร้อมคำอธิบาย, ผู้เล่นที่เชื่อข้อความผิดจะถูกปรับเป็น `DEAD` ทันทีและแต้มกลายเป็น 0 |
| **TRANSITION** | 3 วินาที | เตือนเตรียมตัวรอบถัดไป (รอบ 1 → 2 → 3 → 4 → 5 → 6) |
| **RESULT** | ไม่จำกัด | สรุปผลผู้รอดชีวิตทั้งหมด 6 รอบ, แสดงคะแนนเฉลี่ยของกลุ่ม, รอยืนยันจากผู้จัด |
| **COMPLETED** | - | ผู้จัดกดยืนยันผล ย้ายสไลด์ไปคิว `07.02` อัตโนมัติ |

## 5. กฎคะแนนและการคำนวณ (Scoring & Elimination Rules)

1. **การตัดสินใจเดี่ยว (Individual Scoring):**
   - **เชื่อ ข้อความที่ถูกต้อง:** ได้รับ `+300` แต้ม, รอดชีวิต (`ALIVE`)
   - **เชื่อ ข้อความที่ผิด / ภาพหลอน:** **เสียชีวิตทันที (`DEAD`)**, คะแนนสะสมทั้งหมดถูกรีเซ็ตเป็น `0` แต้ม, ถูกคัดออกจากการเล่นในรอบถัดไป
   - **ไม่เชื่อ ข้อความที่ผิด / ภาพหลอน:** ได้รับ `+100` แต้ม, รอดชีวิต (`ALIVE`)
   - **ไม่เชื่อ ข้อความที่ถูกต้อง:** ได้รับ `+0` แต้ม, รอดชีวิต (`ALIVE`)
   - **ไม่ตอบ / หมดเวลา:** ได้รับ `+0` แต้ม, รอดชีวิต (`ALIVE`)

2. **คะแนนกลุ่ม (Group Scoring & Denominator Invariant):**
   $$\text{Group Score} = \frac{\sum \text{Scores of Survived Members in Group}}{\text{Total Starting Members in Roster at Start}}$$
   - **ผู้เล่นที่เสียชีวิตยังคงถูกนับเป็นตัวหารของกลุ่มเสมอ** เพื่อสะท้อนผลลัพธ์ของการเชื่อ AI ผิดพลาดต่อส่วนรวม
   - คะแนนเต็มเดี่ยวสูงสุด = `1,200` แต้ม (ตอบเชื่อถูก 4 รอบ)

## 6. เสียงและการเคลื่อนไหว (Audio & Animation Synthesis)

- **Procedural Web Audio API (`src/game-client/roulette-sound.ts`):**
  - ไม่พึ่งพาไฟล์เสียงภายนอก ทำงานออฟไลน์ 100% ตอบสนองทันที (<1ms)
  - `playTick()`: เสียงคลิกความถี่ 880Hz → 440Hz ในช่วงนับถอยหลัง
  - `playLock()`: เสียงคลิกล็อกกลไก 580Hz & 720Hz เมื่อผู้เล่นกดปุ่มเลือก
  - `playSurvive()`: คอร์ดประสานเสียงสวรรค์ C5 (523Hz) - E5 (659Hz) - G5 (784Hz) - C6 (1046Hz) เมื่อรอดชีวิต
  - `playDeath()`: เสียงคลื่นเลื่อย Sawtooth ดำดิ่ง 196Hz ลงไปถึง 40Hz พร้อม Low-pass filter เมื่อผู้เล่นเสียชีวิต
  - `playReveal()`: เสียงคอร์ดตึงเครียดช่วงเฉลยผล
- **Motion & Reduced Motion:**
  - การ์ดเฉลยใช้แอนิเมชัน `reveal-pop` ขยายตัวนุ่มนวล
  - นาฬิกาช่วงคับขันเต้นเป็นจังหวะหัวใจ `roulette-heartbeat`
  - รองรับ `prefers-reduced-motion`
