# เสียงของการเดินทาง · HUMAN vs AI

เสียงทำหน้าที่บอกระยะ ทิศทาง และวัสดุของสถานที่ โดยเว้นช่วงอ่านให้ผู้พูด โปรแกรมไม่เพิ่มคำพูด เพลงประกอบทั้งงาน หรือเสียงปรบมืออัตโนมัติ

## โครงจังหวะ

| จังหวะ | เวลาในคิวปกติ | เสียงและหน้าที่ |
|---|---:|---|
| ออกจากฉาก | 0.00–0.50 s | ลมสั้นนุ่มตามข้อความที่ถอยจากระนาบ |
| เดินทาง | 0.16–1.81 s | ลมผ่านพื้นผิว นุ่มและไม่มี pitch glide หรือระฆัง; stereo pan โค้งจาก −0.12 ไป +0.12 ตามทิศทางกล้อง |
| ลงจอด | 1.72 s | คิวปลายทางเบาหนึ่งครั้ง หลังกล้องถึงที่ ไม่ซ้อนเสียงแก้วอีกชั้น |
| ช่วงอ่าน | หลัง 3.5 s | เงียบในค่าเริ่มต้น; เปิดบรรยากาศเพิ่มได้ โดยเริ่ม fade ที่ 2.8 s |

ฉากแรกใช้เสียงปลายทางที่ 0.32 s. เสียงเดินทางใช้คิวเต็มเหมือนกันทุกเครื่องและเดินตามกล้องเสมอ. เกม คะแนน และรางวัลมีเพียงสัมผัสกระดาษเบา ๆ 0.25 s ไม่มีลูป. การเปิดเสียงขณะคิวผ่านช่วงเข้าแล้วจะไม่ย้อนเอฟเฟกต์ต้นคิว

แก้จาก feedback เสียงเลื่อนฉาก: stem เดินทางลด peak จาก 0.28 เป็น 0.15, gain จาก 0.66 เป็น 0.48; ย่าน air อยู่ประมาณ 240–2700 Hz และมวลต่ำ 110–720 Hz. ตัดโทนขึ้น/ลงและระฆังผ่านกรอบออก ลด departure ด้วย และลดคิวปลายทางเหลือ gain 0.30–0.38. ลูปค้อนและวัตถุประกอบเป็นภาพ ไม่มีเสียงทุบซ้ำระหว่างการพูด. การวัดยืนยันด้านเทคนิค ส่วนความน่าฟังต้องประเมินจากการฟังจริง

## มิกซ์และการควบคุม

- 31 ไฟล์ต้นฉบับสังเคราะห์ด้วย Python/NumPy: 20 effects + 11 seamless ambience loops. 48 kHz, stereo, PCM16 WAV อยู่ในเครื่อง ไม่มีตัวอย่างเสียงหรือเพลงของบุคคลอื่น. ขั้นตอนและ SHA อยู่ใน `public/assets/audio/manifest.json`
- Chain: high-pass 65 Hz → peaking 1.6 kHz / −8 dB / Q 0.65 เมื่อเปิด “เว้นพื้นที่ให้เสียงผู้พูด” → low-pass 7.8 kHz → compressor −20 dB / ratio 3 / attack 8 ms / release 180 ms → master 65% → oversampled soft ceiling → output
- Speech-space เป็น EQ ที่เว้นย่านเสียงพูด ไม่ใช่ automatic ducking หรือ dynamic voiceover carve. ไม่มีการบันทึกหรือรับเสียงไมโครโฟน จึงไม่อ้างว่าตรวจระดับผู้พูดจริง
- Soft ceiling จำกัด amplitude เชิงดิจิทัล; ระดับเสียงห้องจริงขึ้นกับเครื่องขยาย ลำโพง และไมโครโฟน ต้องซ้อมก่อนขึ้นเวที. ค่าดิจิทัลไม่ได้รับประกันระดับ dB SPL หรือ intelligibility หน้างาน
- เปิด “เสียง · ปิด” หรือกด M ที่จอฉายหนึ่งครั้ง จากนั้นซ่อน controls ด้วย H ได้. ตั้งเสียง: master volume, speech-space, ambience และปุ่มทดสอบเสียง. หน้าต่างผู้พูดปรับและปิดเสียงของจอฉายผ่าน BroadcastChannel ไม่สร้าง AudioContext อีกตัว
- โหลดเสียงหลังการกดเปิดโดยไม่บล็อก fonts/images. หากเสียงหาย มีข้อความสถานะและปิดเสียง สไลด์ยังเดินคิวได้. Refresh จะกลับมารอเปิดเสียงใหม่และเก็บเพียง volume/ambience/EQ
- Pause ดับจอ และซ่อนแท็บ fade เสียงสั้นก่อนหยุด; resume และ seek สร้าง sample offset จากเวลาเดียวกับภาพ. เวลา audio hardware ต่างจาก cue clock เกิน 90 ms จะปรับตำแหน่งพร้อม fade. ไม่ใช้ audio timer หรือ animation loop อีกตัว
- ขณะเปลี่ยนคิว ตัดเสียงเดิมพร้อม fade 25 ms; ambience เดิม fade 400 ms และปลายทางใหม่ fade 650 ms. การเปลี่ยนคิวซ้ำจะไม่ยืดเวลาหยุดเสียงที่กำลัง fade และจะยกเลิกเสียงที่ยังไม่เริ่มภายใน 10 ms; pause ย่น tail ที่เหลือให้หยุดทันที. ลูปสร้างจาก FFT ที่เป็นคาบ 8 s จึงไม่มี envelope reset ที่รอยต่อ

## Runtime และแหล่งอ้างอิงเทคนิค

งานนี้ใช้ React/GSAP/Three.js กับ Web Audio ของ browser ที่มีอยู่ ไม่แปลงโปรเจกต์เป็น HyperFrames CLI. นำแนวคิดแยก role / submix / filter ก่อน dynamics / automation / ceiling และตรวจ render จาก hyperframes-audio มาใช้กับระบบปัจจุบัน. Live และ offline render เรียก mixGraph เดียวกัน

[MDN Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices) — buffer สำหรับ SFX สั้น การเริ่ม context จาก gesture และ controls; [AudioBufferSourceNode.start](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start) — scheduled start กับ sample offset

## สิ่งที่ส่งตรวจ

`qa/card-rhythm/creative-preview.mp4` เป็นคลิปปัจจุบัน 30 s: เปิดเรื่อง → หน้าเห็ด → ตรวจคำตอบ พร้อมเสียงจาก production mix แบบ effects-only. เสียงเข้าหน้าเห็ดใช้ filtered noise ย่าน body 85–650 Hz และ air 280–1700 Hz, envelope นุ่ม ความยาว 1.05 s และ gain 0.30 ไม่มี pitched oscillator. ไฟล์ต้นฉบับมี peak −14.42 dBFS และ RMS −30.00 dBFS; ดู `qa/card-rhythm/mushroom-sound-check.json`. `qa/creative-direction/sound-checks.json` กับ `sound-measurements.json` ตรวจใหม่ครบ 42 คิวแล้ว ไม่มี clipping และไม่เล่นเสียงทุบวน. ผลวัดนี้เป็นการตรวจทางเทคนิค ยังไม่ได้ฟังประเมินความน่าฟังหรือทดสอบลำโพงหน้างาน

`qa/sound-journey-preview.mp4` เป็นประวัติภาพเดินทาง 6 เส้นทาง 24 s ก่อนปรับเสียงเดินทางและหน้าเห็ด; เปิด ambience เพื่อให้เทียบสถานที่ได้. ทุก 4 s เป็นตัวอย่างใหม่ มี cut จงใจ. `qa/audio-checks.json` กับ `qa/audio-measurements.json` เป็นผลตรวจระบบเสียงรุ่นนั้น ไม่มีเสียงผู้พูดอยู่ในคลิป

การ render ซ้ำตรวจ timing/phase และ waveform โดยยอมรับ numerical rounding ไม่เกิน 1 ขั้น PCM16 ในไม่เกิน 0.1% ของ samples. ระหว่างตรวจพบต่าง 1 ขั้นใน 440/2,304,000 samples (0.0191%), RMS ของผลต่าง −127.50 dBFS และ peak ต่าง 0.00000181 dB; ไม่พบการเลื่อนเวลา. จึงไม่อ้างว่าไฟล์จะเหมือนกันทุก byte ข้าม native DSP runs. ดู `qa/audio-rounding.json` สำหรับค่าที่วัดก่อนยืนยัน tolerance
